Pertemuan 1: Analisis Masalah & IPO Lanjut

Menulis kode secara langsung tanpa perencanaan adalah jebakan yang dapat menghasilkan Spaghetti Code [4]. Solusinya adalah memecah masalah besar menjadi sub-masalah kecil (Dekomposisi) [5]. Setiap pemecahan harus dianalisis menggunakan kerangka IPO (Input-Process-Output) [6].

  • Input: Data mentah yang masuk, diterjemahkan menjadi parameter fungsi [6, 7].
  • Process: Logika pengolahan data, diterjemahkan menjadi badan (body) algoritma fungsi [6, 7].
  • Output: Hasil akhir, diterjemahkan menjadi nilai kembali (Return Value) [6, 7].

Pertemuan 2: Pemrograman Modular

Pemrograman modular bertujuan memecah satu program raksasa (monolitik) menjadi fungsi-fungsi kecil yang spesifik, independen, dan terukur untuk mengisolasi kompleksitas [8, 9]. Arsitekturnya memisahkan lapisan definisi fungsi (cetak biru) dan Program Utama yang khusus mengatur alur eksekusi [10, 11].

Terdapat empat prinsip emas dalam pemrograman modular [12]:

  • Single Responsibility: Satu fungsi hanya mengerjakan tepat satu tugas logis [12].
  • Reusability: Fungsi dapat digunakan ulang di bagian lain atau proyek berbeda [12].
  • Readability: Struktur kode lebih rapi dan sangat mudah dibaca manusia [12].
  • Maintainability: Memudahkan pelacakan error (debugging) dan penambahan fitur [12].

Pertemuan 3: Rekursi vs Iterasi

Rekursi adalah teknik di mana fungsi memanggil dirinya sendiri secara terus-menerus untuk memecahkan versi masalah yang semakin kecil [13]. Walaupun kodenya lebih elegan, rekursi sangat boros memori karena menumpuk setiap pemanggilan di dalam Call Stack sistem [14, 15]. Sedangkan iterasi menggunakan perulangan loop yang lebih ramah memori karena hanya memperbarui variabel lokal [15, 16].

Contoh Kode Python: Penghitungan Faktorial

# 1. Implementasi Rekursif (Memanggil diri sendiri)
def faktorial_rekursif(n):
    if n == 0: # Base Case
        return 1
    else: # Recursive Case
        return n * faktorial_rekursif(n - 1)

# 2. Implementasi Iteratif (Menggunakan Loop)
def faktorial_iteratif(n):
    hasil = 1
    for i in range(1, n + 1):
        hasil *= i
    return hasil

Pertemuan 4: Kompleksitas Algoritma (Notasi Big-O)

Efisiensi program diukur berdasarkan pertumbuhan jumlah langkah eksekusi relatif terhadap ukuran input data (n), bukan waktu detik aktual [17, 18].

  • O(1) - Waktu Konstan: Paling efisien, jumlah eksekusi mutlak tidak berubah [19].
  • O(n) - Waktu Linear: Waktu eksekusi berjalan beriringan dengan ukuran data (terjadi di Single Loop) [20].
  • O(n²) - Waktu Kuadratik: Membahayakan memori pada data besar karena setiap elemen diproses berulang terhadap elemen lainnya (terjadi di Nested Loop) [21, 22].

Contoh Kode Python: O(n) vs O(n²)

# O(n) - Loop Tunggal (Waktu Linear)
n = int(input("Masukkan nilai n: "))
count_n = 0
for i in range(n):
    count_n += 1
print("Jumlah iterasi O(n):", count_n)

# O(n²) - Loop Bersarang (Waktu Kuadratik)
count_n_kuadrat = 0
for i in range(n):
    for j in range(n):
        count_n_kuadrat += 1
print("Jumlah iterasi O(n²):", count_n_kuadrat)
