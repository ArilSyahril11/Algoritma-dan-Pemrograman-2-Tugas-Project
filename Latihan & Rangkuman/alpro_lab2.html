Implementasi IPO: Kasus Diskon

Sebelum menulis kode, kita memetakan data. Dalam kasus diskon belanja, kita harus menentukan ambang batas (threshold) dan variabel yang akan diproses.

📑 Alur Logika (IPO)

INPUT Total Belanja (float)
PROCESS Cek syarat diskon (10% / 5% / 0%)
OUTPUT Nominal Diskon & Total Bayar

Visualisasi Distribusi Diskon

p1_diskon.py
# Input: Mengambil data dari user
belanja = float(input("Total: "))

# Process: Logika penentuan diskon
if belanja >= 500000:
    diskon = 0.10 * belanja
elif belanja >= 250000:
    diskon = 0.05 * belanja
else:
    diskon = 0

# Kalkulasi akhir
total_bayar = belanja - diskon

# Output: Menampilkan hasil
print(f"Diskon: {diskon}")
print(f"Bayar: {total_bayar}")

Pemrograman Modular: Kalkulator Bangun Datar

Alih-alih menumpuk semua kode di satu tempat, kita membaginya menjadi fungsi-fungsi spesifik. Ini memudahkan pengujian (unit testing) dan pemeliharaan kode.

🏗️ Arsitektur Modular
🟦

luas_persegi(s)

Menerima 1 parameter, mengembalikan hasil s * s

🚥

Main Program

Mengatur alur menu dan input user

⭕

luas_lingkaran(r)

Menggunakan library math untuk nilai PI

p2_modular_shapes.py
import math

# Modul 1: Fungsi untuk Persegi
def luas_persegi(sisi):
    return sisi * sisi

# Modul 2: Fungsi untuk Lingkaran
def luas_lingkaran(jari):
    return math.pi * jari * jari

# Program Utama (Main)
print("--- Menu Luas ---")
pilih = int(input("1. Persegi, 2. Lingkaran: "))

if pilih == 1:
    s = float(input("Sisi: "))
    print("Hasil:", luas_persegi(s))
elif pilih == 2:
    r = float(input("Jari-jari: "))
    print("Hasil:", luas_lingkaran(r))

Rekursi vs Iterasi: Faktorial

Duel Performa: Memory vs Speed

Mengapa Rekursi Terasa Berat?

Setiap kali fungsi rekursif memanggil dirinya sendiri, OS menciptakan "Stack Frame" baru di memori. Bayangkan menumpuk piring; semakin tinggi tumpukannya, semakin besar risiko Stack Overflow.

Versi Iteratif (Hemat Memori)
def faktorial_iteratif(n):
    hasil = 1
    for i in range(1, n + 1):
        hasil *= i
    return hasil
Versi Rekursif (Elegan/Matematis)
def faktorial_rekursif(n):
    # Base Case (Penghenti)
    if n == 0 or n == 1:
        return 1
    # Recursive Case (Aksi)
    else:
        return n * faktorial_rekursif(n - 1)
