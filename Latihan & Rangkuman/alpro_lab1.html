p1_diskon_lab.py 🐍 Python 
# INPUT: Meminta data dari pengguna
total_belanja = float(input("Masukkan total: "))

# PROCESS: Logika penentuan diskon (Analisis IPO)
if total_belanja >= 500000:
    diskon = 0.2 * total_belanja
elif total_belanja >= 250000:
    diskon = 0.1 * total_belanja
else:
    diskon = 0

# Kalkulasi hasil bayar
total_bayar = total_belanja - diskon

# OUTPUT: Menampilkan hasil akhir
print(f"Diskon  : Rp {diskon:,.0f}")
print(f"Bayar   : Rp {total_bayar:,.0f}")

# Catatan Kritis: Pastikan tipe data 
# selalu dikonversi (casting) karena 
# input() menghasilkan String.
Pilar 2: Dekomposisi Modular

Arsitektur Fungsi Bangun Datar

Memecah masalah besar menjadi modul kecil (Single Responsibility Principle). Setiap fungsi hanya boleh melakukan satu hal dengan baik.

📐

Modul Perhitungan

Fungsi murni yang melakukan kalkulasi matematis tanpa gangguan input/output.

🎮

Modul Antarmuka

Menangani interaksi pengguna, menu, dan format tampilan data.

✅

Modul Validasi

Memastikan data yang masuk (seperti jari-jari) tidak bernilai negatif.

p2_modular_calc.py 🧩 Modular Design 
import math

# MODUL 1: Fungsi murni (Logic Only)
def hitung_luas_lingkaran(r):
    return math.pi * r * r

# MODUL 2: Validasi (Logic Only)
def is_valid(nilai):
    return nilai > 0

# MODUL 3: Program Utama (Interaksi)
def main():
    jari = float(input("Jari-jari: "))
    if is_valid(jari):
        luas = hitung_luas_lingkaran(jari)
        print(f"Luas: {luas:.2f}")
    else:
        print("Error: Input harus positif!")

if __name__ == "__main__":
    main()
Pilar 3: Rekursi vs Iterasi

Anatomi Memori: Faktorial

Perbandingan efisiensi ruang antara pendekatan loop (Iterasi) dan tumpukan fungsi (Rekursi). Analisis kritis menunjukkan rekursi memiliki beban overhead yang lebih besar pada memori sistem.

Versi Rekursif (Memakan Stack)
def faktorial_rekursif(n):
    if n == 1: # Base Case
        return 1
    else: # Recursive Case
        return n * faktorial_rekursif(n - 1)

# Bahaya: Jika n terlalu besar (misal 1000)
# sistem akan mengalami RecursionError.
Versi Iteratif (Hemat Memori)
def faktorial_iteratif(n):
    hasil = 1
    for i in range(1, n + 1):
        hasil *= i
    return hasil

# Aman: Menggunakan frame memori tunggal
# yang sama sepanjang perulangan.

Kesimpulan Analitis

Seorang arsitek sistem tidak hanya mengejar kode yang elegan (Rekursi), tetapi juga kode yang pragmatis dan efisien (Modular/Iterasi) demi stabilitas perangkat lunak dalam jangka panjang.
